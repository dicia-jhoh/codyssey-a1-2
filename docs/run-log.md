# 실행 결과 로그 (실측)

터미널에서 실제로 실행한 출력 전문이다. 스크린샷 대신 텍스트로 남긴다 — 복사·검색·대조가 되기 때문.

## 1. 입력값 검증 · 키 미설정 안내

```
$ python main.py -date 2026-13-99
[중단] 날짜 형식이 올바르지 않습니다: '2026-13-99'
usage: main.py [-h] -date DATE [--size SIZE] [--no-cache]

날짜를 주면 여행지를 추천받아 맛집까지 찾아 리포트를 만듭니다.

options:

$ python main.py -date 2026-09-15   # 키 미설정 상태

[중단] 환경변수 OPENAI_API_KEY 가 설정되어 있지 않습니다.

키를 설정하는 방법 (셋 중 하나):

  1) macOS / Linux — 지금 터미널에만 적용
     export OPENAI_API_KEY="YOUR_KEY"

  2) Windows PowerShell — 지금 세션에만 적용
     $env:OPENAI_API_KEY="YOUR_KEY"

  3) 프로젝트 폴더에 .env 파일 만들기 (권장, 매번 안 쳐도 됨)
     OPENAI_API_KEY=YOUR_KEY
     ※ .env 는 .gitignore 에 들어 있어 GitHub 에 올라가지 않습니다.
```

날짜 형식이 틀리면 **사용법을 출력하고 종료**한다(종료 코드 1). 키가 없으면 즉시 멈추고 운영체제별 설정 방법을 안내한다 — 키 값 자체는 어디에도 출력하지 않는다.

## 2. 리포트 생성 (오프라인 데모)

`python demo_offline.py` — API 키 없이 3단계(리포트)만 확인한다. 실제 API 응답과 같은 구조의 예시 데이터를 넣었다.

```
== 사례 1: 정상(맛집 2곳) ==
# demo-2026-09-15 여행 리포트 — 강릉

## 추천 지역과 이유

**강릉**

여름 성수기가 지나 숙소·해변이 한산해집니다. 바다와 커피거리를 하루에 묶을 수 있어 1일 일정으로 밀도가 높고, KTX 로 서울에서 2시간이면 닿아 이동 부담이 적습니다.

## 날씨

9월 중순 강릉은 낮 23~26도로 선선하고 습도가 낮아 해안 산책에 좋습니다.

## 행사·축제

- 강릉커피축제(가을 시즌)
- 정동진 해변 야간 조명

## 맛집

| 이름 | 주소 | 분류 | 링크 |
|---|---|---|---|
| 초당순두부마을 | 강원 강릉시 초당순두부길 30 | 두부요리 | [지도](https://place.map.kakao.com/00000001) |
| 강릉 회센터 | 강원 강릉시 창해로 100 | 회 | [지도](https://place.map.kakao.com/00000002) |

## 1일 일정 제안

- **오전**: 강릉 도착, 대표 명소 한 곳 둘러보기
- **오후**: 점심(초당순두부마을) 후 시내·해안 산책, 카페 휴식
- **저녁**: 저녁 식사(강릉 회센터) 후 야경 스팟 방문

## errors

- 없음


== 사례 2: 맛집 0건 + 오류 발생(리포트는 계속 생성된다) ==

- 정동진 해변 야간 조명

## 맛집

데이터 없음 (검색 결과가 없거나 API 호출에 실패했습니다)

- **저녁**: 저녁 식사(현지 맛집) 후 야경 스팟 방문

- 지도 API HTTP 401: 인증 실패. REST API 키 값·헤더 형식을 확인하세요


저장: results/demo-2026-09-15.md · results/demo-2026-09-15.json
```

**사례 2가 핵심이다** — 맛집이 0건이고 지도 API 가 401 로 실패했는데도 리포트는 정상 생성되고, 맛집 자리에 "데이터 없음", `errors` 섹션에 실패 사유가 남는다.
